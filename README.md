# 🌱 EcoTrace – AI Carbon Footprint Analyzer

EcoTrace is an AI-powered web application that helps users calculate, analyze, and reduce their carbon footprint through personalized sustainability insights.

## 🚀 Features

* Multi-step carbon footprint assessment
* Carbon emission calculation engine
* Interactive dashboard with visual analytics
* Emission breakdown charts
* Comparison with India and Global averages
* Personalized AI-generated sustainability recommendations
* Historical tracking using Local Storage
* Exportable carbon footprint reports
* Achievement and gamification system
* Responsive modern UI

## ⚙️ How It Works

1. User enters lifestyle information.
2. Application calculates carbon emissions from:

   * Transportation
   * Diet
   * Energy Consumption
   * Shopping Habits
3. Carbon score is generated.
4. Dashboard visualizes emissions.
5. AI generates personalized sustainability recommendations.
